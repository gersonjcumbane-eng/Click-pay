## 📌 Visão Geral do Sistema
O **ClickPay Moçambique** é o ERP na nuvem adaptado à legislação moçambicana para micro, pequenas e médias empresas:

* 📑 **Facturação Eletrónica com QR Code AT:** Emissão em segundos com IVA (16%) ou regime simplificado ISPC (3%).
* 💼 **Processamento Salarial (Payroll):** Cálculo automático com tabelas oficiais de **IRPS 2026** e desconto de **INSS (3% trabalhador + 4% patronal)**.
* 🏛️ **Exportação SISSMO:** Geração do ficheiro oficial formatado para envio direto ao INSS.
* ⚡ **Piloto Automático Fintech:** Pagamentos em lote com disparo instantâneo para carteiras móveis **M-Pesa e e-Mola**.
* 📊 **Gestão Comercial & CRM:** Pipeline de negociações, contratos e controlo de tesouraria.

## ⚙️ Deploy Contínuo Automático (CI/CD)
Este repositório está conectado ao **Vercel**. 
Sempre que você fizer um `git push` para a branch `main` (ou `master`), o Vercel:
1. Detecta as alterações automaticamente.
2. Executa a compilação de produção (`npm run build`).
3. Atualiza o site em **https://clickpay.co.mz** em menos de 1 minuto sem precisar de intervenção manual.

## 💻 Como Rodar Localmente

**Pré-requisitos:** Node.js 18+

```bash
# 1. Instalar as dependências
npm install

# 2. Iniciar o servidor de desenvolvimento
npm run dev
```

Aceda a `http://localhost:3000` no seu navegador.
